# tray-view

Windows 托盘进程查看器：点击托盘图标弹出深色列表，查看各进程内存与 CPU 占用（只读，不结束进程）。

## 构建

```powershell
cd tray-view
.\build.ps1
```

生成 `tray-view.exe`，双击运行后图标在系统托盘。

## 使用

- **左键托盘图标**：显示/隐藏进程列表窗口
- 托盘菜单：**显示/隐藏**、**退出**
- 列表每约 2 秒自动刷新（窗口可见时）

## 依赖

- Go 1.22+
- Windows 10/11
- 无需 CGO / MinGW（使用原生 Win32 绘制界面）
