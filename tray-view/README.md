# tray-view

Windows 托盘进程查看器：点击托盘图标弹出深色列表，查看各进程内存与 CPU 占用（只读，不结束进程）。

## 构建

```powershell
cd tray-view
.\build.ps1
```

生成 `tray-view.exe`，双击运行后图标在系统托盘。

## 使用

- 托盘菜单：**显示/隐藏**、**退出**
- **标题栏**：拖动移动窗口；`—` 最小化到托盘；`×` 关闭窗口（不退出程序）
- **复选框**：点击勾选/取消，支持多选（各行独立）
- **排序**：点击表头「名称」「内存」「CPU」切换排序（▲升序 ▼降序）；「内存临时垃圾」与系统进程行始终置顶
- **鼠标悬停**：显示该行的内存 / CPU 文字；未悬停时显示用量条
- **鼠标滚轮 / 右侧滚动条**：拖动滑块或滚轮滚动列表
- 列表每约 4 秒在后台刷新（不阻塞界面）
- 进程图标来自对应可执行文件的系统图标

## 依赖

- Go 1.22+
- Windows 10/11
- 无需 CGO / MinGW（使用原生 Win32 绘制界面）
